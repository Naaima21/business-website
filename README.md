# BrandX Agency — Business Website

A fully responsive business/agency landing page built with vanilla HTML, CSS, and JavaScript. Designed as a real-world freelance-style project showcasing modern front-end development practices.

## 🔗 Live Demo

https://naaima21.github.io/business-website/

## ✨ Features

- Fully responsive design (desktop, tablet, and mobile breakpoints)
- Mobile hamburger menu with icon toggle and keyboard accessibility
- Active navigation link highlighting on scroll
- Contact form with client-side validation (empty field + email format check)
- Auto-clearing success/error form messages
- Smooth scrolling and hover animations
- Clean, semantic HTML structure

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, Media Queries)
- Vanilla JavaScript (DOM Manipulation, Event Listeners)

## 📱 Responsive Breakpoints

- Desktop: 1024px and above
- Tablet: up to 1024px
- Mobile: up to 768px

## 📂 Project Structure

```
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 Getting Started

1. Clone the repository
   ```
   git clone https://github.com/Naaima21/business-website.git
   ```
2. Open `index.html` in your browser — no build tools or dependencies required.
